# Code de conduite

La communauté de tedyclivel doit rester accueillante, respectueuse et inclusive.

Les comportements discriminatoires, harcelants ou abusifs ne sont pas acceptés. Les échanges doivent rester constructifs et centrés sur le projet.

Les problèmes de conduite peuvent être signalés de manière privée par les outils de sécurité du dépôt GitHub.
