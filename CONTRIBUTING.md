# Contribuer à tedyclivel

Les contributions sont les bienvenues.

1. Créez une branche dédiée à votre modification.
2. Vérifiez le typage avec `npm run typecheck`.
3. Vérifiez la compilation avec `npm run build`.
4. Ouvrez une pull request décrivant clairement la modification.

Pour signaler un bug, ouvrez une issue sur [tedyclivel/gamePorfolio](http://github.com/tedyclivel/gamePorfolio/issues).

Pour les vulnérabilités, utilisez les outils d’avis de sécurité privés du dépôt.
